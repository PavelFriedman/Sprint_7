# Sprint_7: Автоматизированное тестирование API "Яндекс.Самокат"

Этот проект содержит набор автоматизированных тестов для проверки API сервиса "Яндекс.Самокат". Тестируются следующие сценарии:

- **Создание курьера:**  
  • Успешное создание курьера с валидными данными.  
  • Ошибка при повторном использовании логина.  
  • Ошибка при отсутствии обязательных полей.

- **Логин курьера:**  
  • Успешная аутентификация.  
  • Ошибки при передаче невалидных или пустых данных.

- **Создание заказа:**  
  • Позитивные сценарии создания заказа с разными вариантами цветового параметра  
    (один цвет, два цвета, без цвета).  

- **Список заказов:**  
  • Получение списка заказов и проверка структуры ответа.
